# Motor de contenido inteligente — prototipo servidor
Ejecutar node revision/content-engine.test.mjs. Selección de temas por historial editorial, deduplicación por ID, máximo 3 candidatos por búsqueda, canales revisados, consulta oficial search.list y videos.list, filtro de región, estado público, incrustación y restricciones de edad. El filtro infantil excluye vídeos declarados para niños o de estado desconocido durante el piloto. No demuestra idoneidad. La etiqueta de tema es provisional y debe confirmarse manualmente. Las copias con IDs distintos requieren revisión humana. Todas las propuestas quedan pendientes de revisión.
No publicar este módulo como endpoint abierto. No hay clave real, tarea programada, escritura en base de datos ni integración de catálogo. Para avanzar: habilitar YouTube Data API v3 en Google Cloud, restringir la clave a esa API y guardarla en servidor; definir canales y aprobarlos; comprobar una búsqueda real y reproducción; configurar cola privada, historial, revisión de moderador, cuotas, ejecución programada y caducidad/retirada de datos conforme a políticas. No descargar ni almacenar vídeo ajeno. Revisar plan de alojamiento y sus condiciones antes de programar tareas. No contratar servicios sin autorización.
